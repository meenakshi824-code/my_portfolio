Production Case Study: HTTP 504 Gateway Timeouts

Context: ICICI Lombard production incident

  • First symptom: spikes in HTTP 504 Gateway Timeouts on the API Gateway during peak traffic hours
  • Misleading signal: Grafana showed healthy node CPU/RAM, suggesting the cluster had ample capacity
  • Initial hypothesis: an external cause — high database connections — was investigated first
  • Root cause: overall server CPU usage stayed below 40% while the bottleneck traced back to database connection load, not compute capacity
  • Outcome: correlated Grafana metrics with application logs to isolate the true bottleneck and support resolution
